## 1. Product Overview

**Smart Gym** (product brand: **Nexera**) is a multi-tenant gym operating system. Members scan QR codes on physical machines to log workouts; trainers coach via AI-assisted notes and program assignments; owners run their gym from a dashboard; the platform team operates a global admin console.

**Three product surfaces:**

1. **Mobile App** (Expo / React Native) — for gym members. QR scanning, workout logging, progress, AI coaching, social.
2. **Web App** (Next.js 14 App Router) — three audiences sharing one codebase via route groups:
   - `(member)/*` — mobile-first PWA for members (480px max-width)
   - `(trainer)/*` — desktop layout for trainers
   - `admin/*`, `owner/*`, top-level routes — full desktop dashboard for staff, gym owners, super admins
3. **Public** — `/m/[slug]` machine landing pages reached by scanning a QR.

**Core MVP loop:** member scans machine QR → lands on machine detail → logs sets (reps × weight × RPE) → earns points → app awards badges, updates streak, surfaces in leaderboard / community feed.

## 6.3 Home — `app/(tabs)/index.tsx`

**Purpose:** Daily briefing. What to do today, momentum, AI coaching, community, motivation.

**Load flow** (sequential)
1. Profile (name, avatar)
2. Active workout check
3. Gym membership + Smart Gym score
4. Active AI program (cycles daily schedule)
5. Weekly progress summary
6. Today done? (rest day mode)
7. AI explanation ("why these exercises today")
8. Guardrails (safety nudges)
9. AI coaching insight
10. Coach notes count
11. Streak, leaderboard rank, badges

**Layout (top → bottom)**

1. **HeroZone** — gradient hero card. Avatar (top-left), greeting (`Hey, Alex`), streak number (if enabled), level badge, summary line (`Program Day 3 of 4 · 5 machines · ~45 min`).
2. **PR Celebration banner** (if unseen PRs) — gold left-border, trophy emoji, "New PR(s)!" + dismiss ×, list of up to 3 PRs (badge `Weight | Reps | 1RM`, exercise name, value e.g. `Squat — 225 kg`).
3. **TodayZone** — program-day card. Day name (`Strength Focus`), exercise list (icon + name + sets×reps), `Start Workout` CTA → `/workout/[id]`. If today done: "Great! Rest well" + tomorrow preview. If rest day: rotating recovery tip. If AI coaching enabled: AI rationale text.
4. **Guardrails banner** (if any) — amber, severity dots (red/amber/green), nudges, two CTAs: `Make today lighter` (sets `session_intent='light'`) and `Got it`.
5. **MomentumZone** — three-tile row: streak pill (🔥 + `X week streak`), weekly bar (`3 / 4 this week`), weekly volume (`12.5t`); level card with progress bar.
6. **CommunityPulse** — leaderboard rank card (`Your Rank #12 · 500 pts`) → `/leaderboard`; recent badge (icon + name); coach notes unread count (if `ai_trainer_copilot` flag on).
7. **Training tip** — 💡 + rotating tip (14-tip array indexed by day-of-year).

**Data sources**
- `profiles`, `gym_members`, `workouts`, `ai_programs`, `user_training_profiles`, `workout_exercises`, `sets`
- Services: `streakService`, `leaderboardService`, `badgeService`, `aiService`

**States:** loading (`HomeScreenSkeleton`), error (banner top), no-membership empty.

**Interactions:** tap exercise (add intent), `Start Workout` (creates `in_progress` row → `/workout/[id]`), tap rank (→ leaderboard), tap badge (→ achievements), pull-to-refresh.

## 6.4 Scan QR — `app/(tabs)/scan.tsx`

**Purpose:** Scan a machine's QR to start tracking.

**Permission states:** requesting (spinner) · denied (CTA `Grant Permission`) · granted (camera live).

**Layout (granted)**

- **Camera** (flex 1, ≥280px) — full live view. Overlay with pulsing scan area (220×220, primary border). Hint: "Point at a machine QR code".
- **Bottom context panel** (BlurView iOS / opaque Android, max 260px tall, top-rounded 20px). Scrollable contents:
  - **Stats strip** — left pill `<count> scans today` · right pill `<count> machines used` (divider between).
  - **Today's program machine** (if assigned) — left-bordered card. Label `UP NEXT IN YOUR PROGRAM` (uppercase 11px), machine name, exercise name. Tappable → `/machine/[slug]`.
  - **Recently used** — horizontal scroll of chips (≥100px wide, gap 8); each shows machine name + last-used time. Tappable → `/machine/[slug]`.
  - **Tip** — 💡 + rotating 7-tip array indexed by day-of-year.
- **Error overlay** (if scan fails) — bottom-sheet modal, message, `Scan Again`.

**Data loaded on focus**
- Recent machines (last 5 unique) — `workout_exercises` join `machines` join `workouts`.
- Today's program machine — `ai_programs.program_data` first exercise of today.
- Today scan count — `app_events` where `event_name='qr_scanned'`.
- Total unique machines — distinct `machine_id` across all the user's workout_exercises.

**On scan:** `parseQrCode(data)` → `/machine/[slug]`.

## 6.7 Auth — `app/auth.tsx`

**Purpose:** Phone + OTP sign-in. New members onboard with goal + experience.

**Flow:** progress dots indicator (filled before, elongated current, hollow after).

- **Step 1 — Phone**
  - Heading: "Let's get you set up." (new) / "Welcome back." (returning)
  - First name input (new only) + phone input (`phone-pad`)
  - Primary `Continue →`; secondary toggles between modes
- **Step 2 — OTP**
  - "Enter your code." + sub "We sent a 6-digit code to [phone]"
  - 6-digit input (32px monospace, letter-spacing 12px), auto-submit at 6 digits
  - `Verify →`; `Resend code` (30s cooldown countdown); `Change phone number`
- **Step 3 — Goal** (new only)
  - 4 selectable cards: 💪 Build Muscle (hypertrophy) · 🏋️ Get Stronger (strength) · 🏃 Stay Fit (endurance) · 🤸 General Fitness
- **Step 4 — Experience** (new only)
  - 3 cards: Beginner (<6mo) · Intermediate (6mo–2yr) · Advanced (2yr+); spinner on selected while saving

**On success:** returning → `returnTo` or `/(tabs)`; new → upsert `user_training_profiles`, set `gym_members.onboarding_status='active'`, redirect.

**Data:** Supabase `signInWithOtp` / `verifyOtp`; `profiles` upsert; `user_training_profiles` upsert; `gym_members` update.

## 6.13 Workout Complete — `app/workout/complete/[id].tsx`

**Purpose:** Celebrate, summarize, surface AI insight + guardrails + badges + points.

**Layout**

- 4 stat cards (spring-in stagger) — Exercises · Sets · Reps · Volume · Duration (`MM:SS`).
