PUBLIC API (call sites in 06-05/06/07 depend on this exact signature):
```typescript
export type SendResult = 'sent' | 'skipped' | 'no_devices' | 'error';

export async function sendNotification(input: {
  gym_id: string;
  type: NotificationType;
  title: string;
  body: string;              // NEVER PII: no names, weights, health data, reply text (lock-screen exposure)
  member_id?: string;        // members.id — provide for member-facing sends
  profile_id?: string;       // auth users.id — provide for owner-facing sends (no member row)
  data?: Record<string, string>;
  is_agent_initiated?: boolean;
}): Promise<SendResult>;

export async function resolveOwnerProfileId(admin: SupabaseClient, gymId: string): Promise<string | null>;
export function isInQuietWindow(nowTime: string, start: string, end: string): boolean;
```

GUARD ORDER (implement exactly — tests assert this order via call-count assertions):
1. Resolve identities: if member_id given → fetch members.user_id (profile_id may be null for unclaimed members); if only profile_id given → look up members.id via `user_id = profile_id AND gym_id` (may be null for owners).
2. Dedup (5 min): member-facing → count `notifications` rows (member_id, notification_type = type, created_at > now-5min); owner-only (no member_id) → count `notification_log` rows (profile_id, type, created_at > now-5min). Any hit → return 'skipped'.
3. Inbox write (member-facing only): insert into `notifications` { member_id, gym_id, notification_type: type, title, body, data: {...data, is_agent_initiated: String(!!is_agent_initiated)}, channel: 'push', status: 'sent', sent_at: now }. This happens BEFORE push-preference guards — opted-out members still get inbox history, they provably get no push.
4. Push guards (any failure → return without calling Edge Function): no profile_id → 'no_devices'; prefs row exists AND enabled === false → 'skipped'; CATEGORY_COLUMN_MAP[type] column === false → 'skipped'; quiet_hours_enabled AND isInQuietWindow(UTC now 'HH:MM:SS', start, end) → 'skipped' (unconditional — no urgency exception, per research anti-pattern); hourly cap: notification_log count (profile_id, status='sent', created_at > now-1h) >= 10 → 'skipped'. Missing prefs row = all defaults enabled (research Open Question 2).
5. Deliver: fetch Edge Function with AbortSignal.timeout(8000); data payload includes is_agent_initiated as string. result.sent > 0 → 'sent', else 'no_devices'. Any thrown error → 'error' (log via console.error, never throw to callers).

LOOP SAFETY: this module MUST NOT import or call triggerUptimizeAIAgent (or anything from lib/billing/triggerAgent). The flag only propagates forward in data.
