  <action>
Create the GET route:

1. `verifyStaff('owner')`
2. Run 4 queries in `Promise.all` via admin client:
   - machines count: `.select('id', { count: 'exact', head: true }).eq('gym_id', gym_id).eq('is_active', true)`
   - members count (any member counts, including invited): same pattern on `members` with `.eq('is_active', true)`
   - scan events count: head-count on `machine_scan_events` `.eq('gym_id', gym_id)`
   - billing: `.from('gym_billing').select('subscription_status, trial_ends_at').eq('gym_id', gym_id).maybeSingle()`
3. Response shape:
```typescript
{
  checklist: { has_machine: boolean; has_members: boolean; has_shared_qr: boolean },
  trial: { is_trialing: boolean; trial_ends_at: string | null; days_remaining: number | null }
}
```
`is_trialing = billing?.subscription_status === 'trialing'`; `days_remaining = is_trialing && trial_ends_at ? Math.max(0, Math.ceil((Date.parse(trial_ends_at) - Date.now()) / 86_400_000)) : null`.

Extract the days-remaining calc as an exported pure helper `computeDaysRemaining(trialEndsAt: string | null, now?: number): number | null` in the same file so tests hit it directly with fixed timestamps.
